# Jury brief — commercial viability and pilot path

PREVIA is a deployed bilingual research prototype. It tests transparent screening-capacity allocation rules on synthetic data. It is not yet a clinically validated device and has not demonstrated reduced cardiovascular events.

## Corrected offer and figures

- supervised pilot: €12,000;
- campaign: €2,500;
- annual licence: €15,000;
- no supplementary per-profile revenue is recognised.

Modeled margins range from 27.96% to 57.78%, but costs are assumptions unsupported by invoices or quotes. Conditional break-even is four complete campaigns or one complete licence.

## Available scientific evidence

Chantier 15 contains 360 reproducible synthetic results. It demonstrates allocation-rule consistency. WHO-chart coverage is dependent on the same chart and is not independent clinical validation. Random selection is a pseudorandom comparator, not opportunistic or first-come-first-served care.

## Proposed pilot

A real-person pilot requires prior approvals, a local clinical protocol, data governance, security, and human supervision. Completeness, time, availability, safety, citation validity, appropriate referral, and follow-up are **measures to evaluate**, not achieved results.

## Code status

The GitHub repository is public but has no `LICENSE` file. The code is viewable; no general reuse right is granted. Open-Core may be claimed only after an explicit licence and component boundary are published.

## Jury request

Support regulated preparation and supervised evaluation: verify actual costs, conduct user research, approve the protocol, and prospectively measure safety, timeliness, follow-up, and group differences.
